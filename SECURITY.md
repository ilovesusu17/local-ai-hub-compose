# Security Policy

## Supported Versions

We actively maintain security for the latest release. Please keep your installation up to date.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅                 |
| < 0.1   | ❌                 |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please follow these steps:

1. **Do not open a public issue** describing the vulnerability
2. Email us at: `your-email@example.com` (replace with your actual contact)
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fixes (if any)

We will respond within 48 hours and work with you to resolve the issue.

## Security Best Practices

- Never commit `.env` files or API keys to the repository
- Use strong passwords for database credentials
- Keep Docker containers updated
- Regularly review Docker Compose configurations
- Monitor container logs for suspicious activity
